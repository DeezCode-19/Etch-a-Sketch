# Etch-a-Sketch

A browser-based Etch-a-Sketch project built as part of [The Odin Project](https://www.theodinproject.com/).

## About

This is a simple interactive Etch-a-Sketch where you can draw on a grid using your mouse.

You can:

* Draw using RGB colors
* Draw with black
* Erase parts of the drawing
* Clear the whole grid
* Change the grid size using the slider

## Built With

* HTML
* CSS
* JavaScript

## What I Learned

While making this project, I practiced:

* Creating grid elements with JavaScript
* Manipulating the DOM
* Working with event listeners
* Using CSS Grid
* Using functions and loops
* Handling mouse events
* Working with JavaScript variables and conditions
* Building an interactive webpage

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
