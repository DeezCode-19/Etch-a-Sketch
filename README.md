# Etch-a-Sketch

A browser-based Etch-a-Sketch project built as part of [The Odin Project](https://www.theodinproject.com/).

## About

This project is an interactive Etch-a-Sketch where users can draw by hovering over a grid of squares.

The user can:

* Draw by hovering over the grid
* Change the grid size
* Clear the drawing
* Create a new grid

## Built With

* HTML
* CSS
* JavaScript

## What I Learned

Through this project, I practiced:

* Using JavaScript to dynamically create HTML elements
* Manipulating the DOM
* Adding and handling event listeners
* Using CSS Grid
* Working with functions and loops
* Getting user input with prompts/buttons
* Creating an interactive webpage with JavaScript

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## Project Goals

This project was created to practice DOM manipulation, JavaScript fundamentals, and building interactive web pages.
